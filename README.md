# 퍼피런 (PuppyRun)

반려견과의 **산책 기록**과 **건강 관리**를 한곳에서 하는 모바일 앱입니다.  
GPS로 산책 경로·거리·페이스를 추적하고, 접종·알러지·투약·체중 등 케어 정보를 관리합니다.

> 우리 아이와의 산책을 기록하고 건강까지 함께 관리해 보세요

---

## 서비스 소개

퍼피런은 산책 순간을 기록하는 데 그치지 않고, 반려견의 일상 건강까지 이어지도록 설계했습니다.

- **산책** — Google Maps 위에서 실시간 GPS로 경로를 그리고, 거리·페이스를 측정합니다. 앱이 백그라운드에 있어도 추적이 이어집니다.
- **기록** — 산책 종료 후 요약 화면, 인증 셀카, 일기까지 남겨 피드로 남깁니다.
- **케어** — 반려견별 접종·알러지·투약·체중을 관리하고, 홈에서 오늘의 상태와 통계를 한눈에 봅니다.
- **가이드** — 견종 정보와 반려동물 관련 법·규정을 검색해 참고할 수 있습니다.
- **온보딩** — 카카오 / Google 소셜 로그인 후 기본 정보·건강 정보·약관 동의로 바로 시작할 수 있습니다.

| 탭     | 역할                                                    |
| ------ | ------------------------------------------------------- |
| 홈     | 오늘의 산책 요약, 날씨, 산책 점수, 주간·월간 통계, 알람 |
| 산책   | 지도·추천 경로·실시간 트래킹 → 요약 · 셀카 · 일기       |
| 케어   | 반려견 프로필, 투약 · 체중 · 접종 · 알러지              |
| 마이   | 프로필, 산책 피드, 펫 관리, 멍BTI, 설정                 |
| 가이드 | 견종 검색, 관련 법·규정                                 |

## 주요 구현 포인트

- **백그라운드 산책 추적** — 포그라운드 맵 표시와 백그라운드 위치 태스크를 분리해, 화면을 닫아도 경로·거리 기록이 이어지도록 구성했습니다.
- **지도 · 해딩** — 실시간 위치 마커와 기울기 보정 나침반으로 진행 방향을 표시하고, 산책 중 카메라를 사용자에 맞춰 추정합니다.
- **소셜 로그인** — Android 앱 서명(SHA-1 / 키해시)과 EAS · Play App Signing 환경을 맞춰 카카오·Google OAuth를 연동했습니다.
- **이미지 업로드** — 셀카·프로필 사진을 리사이즈·압축해 서버 용량 제한을 피하도록 처리했습니다.
- **푸시 · 로컬 알람** — FCM으로 서버 알림을 받고, Notifee로 채널·로컬 알람을 구성했습니다.

## 프로젝트 구조

```
app/            # 화면 (auth · onboarding · tabs)
components/     # UI · 지도 · 온보딩 · 시트
hooks/          # 산책 추적 · 권한 · 나침반 등
store/          # Zustand 스토어
util/           # API · auth · location · run · notification
tasks/          # 백그라운드 위치 태스크
```
